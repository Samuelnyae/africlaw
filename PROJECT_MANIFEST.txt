API ENDPOINTS
─────────────

PUBLIC:
  GET /health
    └─ Health check

  POST /whatsapp/webhook
    └─ Twilio webhook (receives messages)

  POST /mpesa/callback
    └─ M-Pesa transaction callback

PROTECTED (Basic Auth):
  GET /admin
    └─ Admin dashboard UI

  GET /admin/data
    └─ Dashboard metrics (JSON)

  GET /api/users
    └─ All users list

  GET /api/conversations/:phoneNumber
    └─ User's message history

  GET /api/mpesa/transactions
    └─ M-Pesa transactions (today)
